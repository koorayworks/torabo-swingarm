# torabo-swingarm

Nape（menbou0202 氏のトラックボール設計）をベースにした、自作用トラックボール
ケースの設計リポジトリ。ケースは build123d（Python）でパラメトリックに生成し、
STL はスクリプトから再生成する方針のため、**正本はスクリプト**とする。

## 路線は2つ

- **Nape Deck（固定式・ディスプレイ付き）**: ESB 受信機＋ST7789 タッチ
  ディスプレイ付き。ファームは `zmk-config-esb-hid-test` の `esb_nape_rx`
  シールド側。ケースはこれから設計する。
- **無線ピボット版（このリポジトリの主対象）**: ディスプレイなし＋BLE 単体。
  ボールを中心に2本のアームが回る。現行は **v19**（印刷確認待ち）。

## 無線ピボット版 v19 の仕様

- 中央ユニット: 34mm ボール、センサーは TANBOKU（PAW3222 ブレークアウト）
- 細アーム（幅 24mm）×2本、2段カラーでピボット、各 2 キー縦並び（計4キー）
- 青ベゼルは回転式スクロールリング（裏面エンコーダスリット 24 本、
  反射型センサー×2 で直交検出）
- 右アーム首元に XIAO nRF52840、左アーム首元に電池 302030 級（約 300mAh）
- 配線は中央ユニット裏面の環状チャネル経由、JST-PH で着脱
- アーム先端の底に滑り止めパッド（Ø10mm 市販品）の埋め込み座 ×2/アーム

## STL の生成

```sh
python3 -m venv .venv-cad
.venv-cad/bin/pip install build123d
.venv-cad/bin/python scripts/build_case_deck_v19.py   # deck19/ に STL 出力
```

レンダーは `scripts/render_deck19.py`（matplotlib による簡易表示）。

## 前提寸法（未実測のものを含む）

- ディスプレイモジュール 31.5×39.0mm（Deck 案用、要ノギス確認）
- TANBOKU レンズ高さ = 基板上面から 3.4mm、ボール 34mm
- XIAO nRF52840: 21.0×17.8mm
